# NotebookLM 研究 Prompt：易經研究網站

- **用途**：為易經研究網站整理可驗證的規則與內容規格。
- **目標筆記本**：易經經典：Guides to the Zhouyi
- **語言**：繁體中文
- **原則**：只使用此筆記本內的來源；若來源沒有明確支持，請標示「來源未說明」，不要自行補全。

## 共用回答規則

請遵守以下規則：

1. 只根據目前筆記本內的來源回答，不使用外部常識補充。
2. 每個重要結論附上來源名稱與 NotebookLM 可提供的引用位置或原文摘錄。
3. 明確區分：
   - 來源直接說明
   - 由多個來源整理出的共通規則
   - 不同版本或流派的差異
   - 來源沒有說明的部分
4. 保留經文原文，不要把現代解釋改寫成經文。
5. 若不同來源使用不同術語或規則，請並列說明，不要擅自選一個當唯一標準。
6. 回答要服務於網站資料模型與規則引擎，不需要產生個人化占斷或命理式結論。

請以「可以轉成程式規則」的方式回答：

3. 6、7、8、9 各自代表老陰、少陽、少陰、老陽中的哪一種。
4. 哪些爻會變，以及變爻後陰陽如何翻轉。

最後請輸出一段「揲蓍法規則草案」，格式如下：

## Prompt 5：網站內容資料規格

請根據本筆記本實際提供的內容，並參考以下外部網站的內容層級，設計一份適合網站使用的資料欄位規格：

請分成四部分：

### A. 卦資料
