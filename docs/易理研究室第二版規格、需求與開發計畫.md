# 易理研究室：第二版規格、需求與開發計畫

- **版本**：v2.0
- **日期**：2026-09-05
- **狀態**：需求與主要規格已確認；尚未開始實作
- **適用專案**：`projects/iching-research/`
- **第一版基礎**：`docs/易經研究網站產品需求文件.md`、`docs/易經研究網站設計書.md`、`docs/易經卦象規則規格書.md`

## 1. 產品目的

新增「易理研究室」，以單一卦、單一爻為研究單位，協助使用者觀察爻辭在不同卦、相似卦象結構與不同上下卦環境中的共同特徵與異常情況。

本功能的核心不是自動解卦，而是：

1. 查看一卦的完整資訊。
2. 選定其中一爻，分析它所在的結構環境。
3. 依上下卦、爻位、陰陽、得位、得中、應、承、乘及連續陰陽等條件，找出 64 卦／384 爻中的比較對象。
4. 並列閱讀相關爻辭、小象、注與來源，支持人工研究與比對。

## 2. 產品邊界

### 2.1 第二版 MVP 包含

- 新增「易理研究室」頁面與主選單入口。
- 可選擇六十四卦及初爻至上爻。
- 顯示所選卦的完整卦級資料與六爻資料。
- 選定一爻後顯示結構分析。
- 顯示整卦的陰陽統計、上下卦統計、相鄰關係與連續陰陽區段。
- 依條件從 384 筆一般爻資料中篩選比較對象。
- 從結果頁 `TEXT / 02` 的每一個變爻卡片跳轉到研究室，並帶入本卦／之卦摘要。

### 2.2 第二版 MVP 不包含

- AI 自動解釋「為什麼這些爻相似」。
- 自動產生吉凶、醫療、投資、法律或個人行動建議。
- 以語意模型判斷爻辭相似度。
- 納甲、五行六親、月建日辰、世應、神煞。
- 《雜卦》或尚秉和《易經象事易學》的完整自動化象學引擎。
- 乾卦用九、坤卦用六的比較搜尋；資料保留在詳細頁，研究室 MVP 先限定一般六爻。

## 3. 資訊架構與使用流程

### 3.1 路由

新增使用者頁面：

```text
易理研究室：#/research
```

主選單增加「易理研究室」入口。

### 3.2 直接研究流程

```text
易理研究室
→ 選擇六十四卦
→ 選擇初爻至上爻
→ 查看整卦資料
→ 查看選定爻的結構摘要
→ 設定比較條件
→ 閱讀符合條件的爻辭清單
```

### 3.3 從結果頁進入

```text
卜卦結果
→ TEXT / 02 變爻爻辭
→ 變爻卡片下方「研究此爻」
→ 易理研究室
→ 自動選取本卦與該變爻
→ 顯示本卦／之卦上下文
```

每一個變爻各自提供「研究此爻」按鈕。研究室的主要研究對象是本卦中的該爻；之卦只作為上下文摘要，不將之卦爻辭誤當成目前研究爻。

目前網站使用的正式名稱是「本卦／之卦」；本文件不採用「支卦」作為資料欄位名稱。

## 4. 研究室畫面規格

### 4.1 卦選擇區

提供：

- 六十四卦搜尋：卦名、卦序。
- 六十四卦選擇器或卡片索引。
- 已選卦的卦序、卦名、上下卦、自然取象與卦象圖。
- 卦辭、彖、大象、注及校訂狀態。
- 六爻列表；點選任一爻即成為研究爻。

### 4.2 研究上下文區

直接進入時顯示：

```text
研究卦：第 63 卦 水火既濟
研究爻：六二
```

從結果頁進入時，額外顯示：

- 本卦卦名、卦序、上下卦與摘要。
- 之卦卦名、卦序、上下卦與摘要。
- 本次變爻位置、爻值、陰陽與「動爻」標籤。
- 清楚標示目前爻辭取自本卦。

使用者問題文字不帶入研究室 URL，也不新增遠端傳送行為。

### 4.3 選定爻資訊區

顯示選定爻的：

- 爻位與爻名。
- 爻值；直接研究固定卦時，以陰陽結構表示，不虛構老陰／老陽。若從結果頁進入，另外顯示本次實際爻值。
- 陰爻／陽爻。
- 得位／失位。
- 得中／不中。
- 對應爻位與正應／無正應。
- 上方、下方鄰爻的爻位與陰陽。
- 承陽／乘剛及其相鄰爻位。
- 所在下卦、上卦，以及上下卦各自的陰陽組成。
- 本爻的爻辭、小象、注、校訂狀態與來源。

### 4.4 整卦環境摘要

至少顯示：

- 六爻總計：幾陰、幾陽。
- 下卦：幾陰、幾陽。
- 上卦：幾陰、幾陽。
- 選定爻的立即上鄰、下鄰；邊界爻顯示「無鄰爻」。
- 整個六爻中的連續同陰／同陽區段。
- 選定爻是否位於某個連續區段中。
- 每個連續區段的起止爻位、陰陽與長度。

「附近」同時採用立即鄰爻與上下卦／整卦統計，不只顯示單一數字。

### 4.5 比較條件區

比較條件採明確篩選，不在 MVP 自動產生不可解釋的相似度分數。

可用條件：

| 條件 | 預設 | 說明 |
|---|---|---|
| 下卦 | 不限 | 例如只找下卦為坎的卦 |
| 上卦 | 不限 | 例如只找上卦為坎的卦 |
| 相同爻位 | 開啟 | 預設比較相同位置；可關閉以搜尋其他爻位 |
| 陰陽 | 不限 | 陰爻或陽爻 |
| 得位／失位 | 不限 | 與選定爻相同或指定狀態 |
| 得中／不中 | 不限 | 與選定爻相同或指定狀態 |
| 應 | 不限 | 正應或無正應 |
| 承／乘 | 不限 | 承陽、乘剛或無指定關係 |
| 連續陰陽長度 | 不限 | 2、3、4，採至少該長度 |
| 是否包含選定爻 | 不限 | 連續區段是否必須包含目前研究爻 |

上下卦條件可獨立設定，因此能支援：

- 「下卦為坎」的比較。
- 「上卦為坎」的比較。
- 同時限制上下卦。
- 不限制爻位，搜尋該結構中的全部爻。

連續陰陽條件搜尋整個六爻中任何位置的連續區段；若勾選「包含選定爻」，則只保留包含目前研究爻的區段。

### 4.6 比較結果區

每筆結果預設顯示摘要卡：

- 卦序、卦名、上下卦與自然取象。
- 比較爻位、爻名與陰陽。
- 得位／失位、得中／不中、應、承／乘。
- 上下鄰爻與連續陰陽摘要。
- 爻辭、小象、注。
- 內容校訂狀態與來源定位。
- 開啟單一卦詳細頁。
- 可展開該卦的完整六爻資料。

預設依卦序、爻位排列，不宣稱排列順序代表「最相似」。

## 5. 結果頁整合規格

`TEXT / 02 變爻爻辭` 的每一張變爻卡片，在注與來源狀態之後加入：

```text
[研究此爻]
```

點擊後帶入：

```text
selectedHexagram: 本卦卦序
selectedLine: 變爻位置 1～6
originalHexagram: 本卦摘要
changedHexagram: 之卦摘要
lineValue: 6 或 9
isChanging: true
```

若有多個變爻，每張卡片的按鈕帶入各自位置，不共用錯誤的研究爻。

研究室可使用 hash query 或等效的前端 route state 傳遞上述資料；不可把使用者問題文字放進 URL。重新整理後至少應保留選定卦與爻，若有結果上下文則一併保留。

## 6. 領域與資料規格

### 6.1 靜態卦的爻結構

研究室直接選擇一卦時，只有陰陽結構，沒有起卦時的老少狀態。為了共用結構分析函式，可使用下列內部標準化：

- 陽爻以固定少陽值 `7` 表示。
- 陰爻以固定少陰值 `8` 表示。
- 這只是靜態分析的內部表示，不在畫面上宣稱這是實際揲蓍結果。

從結果頁帶入時，保留實際 `6` 或 `9`，並在畫面標示動爻。

### 6.2 建議型別

```ts
type ResearchSelection = {
  hexagramSequence: number
  linePosition: number
}

type ResearchContext = {
  original?: HexagramSummary
  changed?: HexagramSummary
  lineValue?: 6 | 9
  isChanging?: boolean
}

type ResearchFilter = {
  upperTrigram?: TrigramName
  lowerTrigram?: TrigramName
  samePosition: boolean
  polarity?: Polarity
  positionStatus?: '得位' | '失位'
  centralStatus?: '得中' | '不中'
  correspondenceStatus?: '正應' | '無正應'
  adjacentRelation?: '承陽' | '乘剛' | '無指定關係'
  runPolarity?: Polarity
  minimumRunLength?: 2 | 3 | 4
  runIncludesSelectedLine?: boolean
}
```

### 6.3 可由資料推導的特徵

比較資料不另外複製 384 筆內容；由既有 `HEXAGRAMS`、`TRIGRAM_BITS`、`line-records.json` 與規則函式推導：

- 六爻陰陽 pattern。
- 上卦、下卦與卦位。
- 陰陽數量。
- 得位、得中、應、承、乘。
- 立即鄰爻。
- 連續陰陽區段。

文字資料仍取自現有正式資料管線，保留 `reviewStatus`、`sourceRef` 與人工備註。

## 7. 開發計畫

### Phase 2.1：研究特徵與規則函式

- 建立由六十四卦 definition 產生六爻陰陽值的函式。
- 建立六爻陰陽計數、上下卦計數與立即鄰爻分析。
- 建立連續陰陽區段分析：任意位置、長度、是否包含指定爻。
- 重用或擴充 `relationships.ts` 的位、應、承、乘分析。
- 建立研究篩選純函式，不匯入 React 或瀏覽器 API。

驗收：固定輸入 64 卦均能取得正確 6 位 pattern；連續區段與篩選測試涵蓋邊界爻。

### Phase 2.2：研究室選擇與完整卦資料

- 新增 `research` route。
- 建立卦搜尋／選擇元件。
- 建立爻位選擇元件。
- 顯示完整卦級資料與六爻資料。
- 顯示選定爻的經文、校訂狀態與來源。
- 新增上下文摘要區。

驗收：64 卦皆可選；每卦六爻皆可選；重新整理不遺失基本選擇。

### Phase 2.3：篩選與比較結果

- 建立上卦、下卦、爻位、陰陽、得位、得中、應、承／乘篩選。
- 建立連續陰陽長度與「包含選定爻」篩選。
- 顯示符合條件的爻辭比較卡片。
- 預設以卦序／爻位排序。
- 支援展開完整資料與開啟卦詳細頁。

驗收：

- 坎下卦搜尋能列出所有下卦為坎的卦。
- 坎上卦搜尋能列出所有上卦為坎的卦。
- 相同爻位開關確實改變結果範圍。
- 連續 3 陽、4 陰等條件能正確篩選。

### Phase 2.4：結果頁跳轉與上下文

- 每個變爻卡加入「研究此爻」。
- 將本卦、之卦、變爻位置與爻值傳入研究室。
- 多變爻逐一測試，避免位置互用。
- 不傳遞使用者問題文字。

驗收：每個變爻按鈕都會選取正確的本卦與爻位，並正確顯示同一次卜卦的之卦摘要。

### Phase 2.5：Responsive、可用性與文件

- 手機版採單欄卡片與可橫向操作的篩選列。
- 長結果清單保留清楚的卦序、爻位與篩選摘要。
- 鍵盤可完成卦、爻與篩選操作。
- 變爻不只依賴顏色辨識。
- 補齊使用說明、來源說明與第二版 release note。

## 8. 測試計畫

### Unit

- 64 卦 pattern 產生正確。
- 乾、坤、坎、離及既濟、未濟代表卦測試。
- 陰陽總數與上下卦總數正確。
- 初爻與上爻的鄰居邊界正確。
- 連續長度 1、2、3、4、6 的區段正確。
- 「包含選定爻」開關正確。
- 上卦／下卦／相同爻位條件組合正確。

### Component／Integration

- 64 卦與六爻選擇可操作。
- 選定爻資料與六爻資料一致。
- 篩選結果、結果筆數與條件摘要一致。
- 384 筆爻資料的內容、狀態與來源不錯置。
- 用九／用六不出現在 MVP 一般六爻搜尋結果。

### E2E

1. 從主選單進入易理研究室。
2. 選取坎卦第二爻，設定下卦為坎並查看比較結果。
3. 選取未濟的下卦離爻，設定上卦為坎並查看比較結果。
4. 設定連續三陽或四陰條件，確認結果符合結構。
5. 從結果頁每一個變爻按「研究此爻」，確認本卦／之卦與爻位帶入正確。
6. 以 360px 手機寬度操作選擇、篩選與結果閱讀。

## 9. 第二版完成條件

- 使用者能從主選單進入「易理研究室」。
- 任一六十四卦、任一普通爻位皆可被選取與研究。
- 選定爻的陰陽、位、應、承、乘、鄰爻及整卦環境均能顯示。
- 能以相同上卦、下卦、爻位及結構條件篩選 384 筆爻資料。
- 能找出連續 2、3、4 個陰爻／陽爻的結構。
- 比較結果能追溯到卦辭、爻辭、小象、注與來源。
- `TEXT / 02` 每個變爻均可正確跳轉並帶入研究上下文。
- 不產生未有來源支持的語意結論或個人化建議。
- lint、typecheck、unit、E2E、build 全部通過。

## 10. 待保留的研究限制

- 「結構相似」只代表篩選條件相同，不代表經文意義必然相同。
- 承、乘仍採 `general-adjacent-yin-yang-v1`，特殊卦例不可自動套用。
- 連續陰陽是形式結構統計，不直接等同於吉凶或經文解釋。
- 《雜卦》與尚秉和象學資料導入後，必須另建來源與流派欄位，不直接混入本版共同篩選規則。
